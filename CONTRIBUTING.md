# Contributing

Thanks for your interest in Echoes.

## Before opening an issue or pull request

- Never include private AI conversation transcripts, personal notes, API keys, browser data, or account information.
- For parser or workflow issues, provide a minimal synthetic example with identifying details removed.
- Keep the Markdown-first, local-first workflow and preserve source traceability.
- Do not change raw source files as part of organization or distillation workflows.

## Pull requests

Describe the user-facing problem, the proposed change, and how you checked it. Keep changes focused and update both Chinese and English documentation when behavior or instructions change.
